# skills

My Claude Code skills.

## Install

Install all of them:

```bash
npx skills add DevKazonovic/skills
```

Or copy one folder from [`skills/`](skills) into `~/.claude/skills/`.

## Skills

- [`brainstorm`](skills/brainstorm/SKILL.md): Judges your idea or plan. You get a verdict, your assumptions with corrections, a full brainstorm and a build order. It never agrees or praises. It runs only when you type `/brainstorm`.
- [`godeye`](skills/godeye/SKILL.md): Builds one interactive page that maps a whole system: every app, service, store and outside dependency, with the calls between them. Click any part to see its details and what it connects to.
- [`missing`](skills/missing/SKILL.md): Lists what your plan or design does not cover yet, split into existing features that must change and new parts still to design, each with a pick. It runs only when you type `/missing`.
- [`ugetme`](skills/ugetme/SKILL.md): Shows you what Claude understood from your prompts in short bullets, then waits for your go before doing any work.
